# CloudPloy

> Deploy anywhere. Deploy to any cloud and VPS from your AI agent.

CloudPloy is a launched deploy control plane. You connect an AI agent with an API token, then deploy and manage apps from Claude Code, Cursor, or any MCP client. Bring a server you already have, or take one from CloudPloy and pay the provider rate for compute. The monthly plan does not mark up compute.

## Product facts

- Deploy from Claude Code, Cursor, or any MCP client
- Create an API token and point your agent at CloudPloy
- Bring your own server, or provision at cost
- Polyglot deploys via Nixpacks (Node, Python, Go, Rust, Ruby, Java, PHP, static)
- WordPress and Laravel one-click presets
- Automatic SSL and zero-downtime deploys
- Supported builds: Node, Python, Go, Rust, Ruby, Java, PHP, and static sites via Nixpacks. WordPress and Laravel have one-click presets.
- Git: GitHub, GitLab, and Bitbucket.
- Connect a server you already have today and pay that provider directly.
- Prepaid AWS provisioning is not available yet.

## Pricing

- Starter ($9.99 per month): Deploy to servers you already own.
- Pro ($19 per month): More servers, bigger ceilings, more seats.
- Scale ($39 per month): Unlimited servers, uncapped size, for agencies.
- Free ($0, free forever): One small server and one app. Free forever.
- Server compute is billed separately at the provider rate.
- Full plan table: https://cloudploy.com/pricing
